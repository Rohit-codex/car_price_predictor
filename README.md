# Car Price Predictor

**Author:** [Rohit Malik](https://github.com/Rohit-codex)

**Project Repository:** [Car Price Predictor on GitHub](https://github.com/Rohit-codex/car_price_predictor)

A machine-learning web application that predicts the approximate selling price of a used car based on details such as company, model, year of purchase, fuel type, and kilometers driven.

## Project Overview

This project uses a **Linear Regression** model to estimate the price of a used car.

The application takes the following inputs:

* Car company
* Car model
* Year of purchase
* Fuel type
* Kilometers driven

It then predicts the approximate selling price of the car.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Linear Regression
* Flask
* HTML and CSS

## Machine Learning Workflow

1. Load the used-car dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis.
4. Prepare the features and target variable.
5. Train a Linear Regression model.
6. Save the trained model.
7. Use Flask to create a web interface for predictions.

## How to Run the Project

### 1. Clone this repository

```bash
git clone https://github.com/Rohit-codex/car_price_predictor.git
cd car_price_predictor
```

### 2. Install the required packages

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python application.py
```

### 4. Open the local website

Open the local URL displayed in the terminal.
